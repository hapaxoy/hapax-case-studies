Play a tender yourself

Pick one of three tenders from this corpus, read the real document, tick the clauses you judge binding, and call bid or no-bid. You are marked in the browser against the same held-out answer key as everyone else, using the same coverage logic as code/mark.py. Nothing you do here is stored or sent anywhere – no cookies, no local storage, no network request. The score exists only on this screen, and only until you leave it.

Method notes – Arm A’s coverage distribution comes from a seeded engagement model calibrated at population level, not from real bidders; Arm B is one deterministic pipeline run per tender, with the model inside the extraction and drafting steps and two mechanical gates checking draft against matrix against facts library. Both arms are marked by the same script, code/mark.py, against a held-out answer key neither arm ever reads. This page is a single self-contained file – all data embedded below, no server, no build step.
